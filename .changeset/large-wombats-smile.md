Replace the throwing per-event `decode*` function with a null-returning `parse*` function (e.g. `parseTradeEvent(event): TradeEvent | null`): `null` on framing or discriminator mismatch, checked before any decoding, while decoder errors still propagate on a matched-but-corrupt body. Each event also gets a boolean `is*` predicate (e.g. `isTradeEvent(event): boolean`) that checks the framing and discriminator bytes without decoding — the tree-shakeable way to filter one event type from a stream — and `parse*` delegates to it. The aggregate `identify*` helper now hoists the shared CPI framing check so foreign data is rejected with a single compare. Events whose only discriminator is the shared framing are excluded from the per-event helpers and the aggregate helpers with a generation-time warning, since the framing alone matches every framed event. Generation now fails fast with an actionable error when generated export names collide (e.g. an event named like the program's aggregate parse helper). Generated helpers carry docblocks stating the null/throw contract and cross-referencing the decode-free alternatives. The new `eventIsFunction` and `eventParseFunction` name transformers replace `eventDecodeFunction`.
